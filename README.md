Локальный **MTProto-прокси** для Telegram, написанный на языке **Rust**. Данная версия адаптирована для удобного использования на настольных ОС (Windows, Linux, macOS) с возможностью гибкой настройки через аргументы командной строки.

**[Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)**

Спасибо авторам этих проектов за базу. Данный репозиторий фокусируется на очистке кода от Android-специфичных зависимостей, добавлении удобного CLI-интерфейса.


## ⚙️ Как это работает

```text
Telegram Client → Локальный MTProto (127.0.0.1:1443) → TG WS Proxy Rust → WSS (CloudFlare / Напрямую) → Telegram DC
```

1. Приложение поднимает локальный MTProto-прокси средствами высокопроизводительного асинхронного движка на языке **Rust**.
2. Перехватывает подключения Telegram через локальный порт, используя сгенерированный или заданный пользователем секретный ключ.
3. Извлекает `DC ID` из исходного пакета и устанавливает защищённое WebSocket (`TLS`) соединение с нужным датацентром Telegram.
4. При необходимости проксирует трафик через CloudFlare (поддержка FakeTLS / `ee`-секретов для обхода DPI).
5. Использует пул предварительных соединений, keepalive-механику и fallback-сценарии для максимальной устойчивости в реальных сетевых условиях.


## 🚀 Возможности

- ⚡ **Высокая производительность:** Минимальное потребление памяти и CPU благодаря компилируемому коду на Rust.
- 🔒 **Поддержка FakeTLS:** Маскировка трафика под обычный HTTPS для обхода блокировок провайдеров.
- 🎛 **Гибкая настройка:** Управление портом, хостом и секретом через аргументы командной строки.
- 🎲 **Автогенерация:** Если секрет не указан, программа безопасно сгенерирует его самостоятельно.
- 🖥 **Кроссплатформенность:** Легко компилируется под Windows, Linux и macOS.


## 💻 Быстрый старт

### 1. Требования
- Установленный [Rust](https://rust-lang.org/) (инструменты `cargo` и `rustc`).
- Установленный [Git](https://git-scm.com/) (для клонирования репозитория).

### 2. Сборка проекта
Откройте терминал в папке с проектом и выполните:
```bash
cargo build --release
```
Скомпилированный исполняемый файл появится в папке `target/release/`.

### 3. Запуск
Вы можете запустить прокси напрямую или через удобный Python-скрипт.

**Примеры запуска через консоль:**
```bash
# Обычный запуск
.\target\release\tgwsproxy.exe

# Запуск через python
python main.py

# Запуск на конкретном порту с заданным 32-значным hex-секретом
.\target\release\tgwsproxy.exe --host 127.0.0.1 --port 1443 --secret aabbccdd11223344aabbccdd11223344

```

После успешного запуска в консоли появится готовая ссылка вида `tg://proxy?...`, которую можно просто скопировать и открыть в Telegram Desktop для автоматической настройки.
